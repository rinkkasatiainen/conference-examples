# Learning log — test journey hub

Keep **full** test-session notes in each folder: [`test-0/learning-log.md`](./test-0/learning-log.md) through
[`test-8/learning-log.md`](./test-8/learning-log.md).

**This page stays short:** after each test step, write **one key takeaway** (one or two sentences) in the matching
section below, then use the link to reopen the detailed log anytime.

**Build track hub:** component steps use [`learning-log.md`](./learning-log.md) — keep build and test takeaways separate
so you can scan each journey later.

**How to work a test step:** [`how-to-test.md`](./how-to-test.md)

**For your facilitator:** use a branch or fork; ping when `npm test` is green for that `test-N/` and your hub line is filled in.
